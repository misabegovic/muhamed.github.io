# Create an index for the resolved-suggestions archive

## Observation

`wiki/muhamed.github.io/ai-suggestions/_archive/` now holds 9 resolved refinement suggestions, but there is no index page. A reader has to list the directory to know what was decided and delivered.

## Why it matters

Without an index, the archive is just a folder of files. A short index page would turn it into a readable log of agent-initiated improvements.

## Suggested action

Create `wiki/muhamed.github.io/ai-suggestions/_archive/index.md` with a table listing each archived suggestion, its resolution date, and a one-line outcome. Link it from `wiki/muhamed.github.io/ai-suggestions/index.md` if that page exists, or from the empty `refinement/` directory note.
