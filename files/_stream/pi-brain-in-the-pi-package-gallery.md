One of the packages circling around the Pi universe 😎 — [pi-brain](https://pi.dev/packages/@misabegovic/pi-brain?name=misabegovic) is up in the [Pi](https://pi.dev/) package gallery, and it's sitting at 257 downloads thus far 😅

For a knowledge-base extension I mostly built to keep my own head straight, that's 257 more installs than I expected. The gallery page shows v0.3.2: the pi-brain extension itself plus the skills, prompts, and themes that ship with it — MIT-licensed, zero runtime dependencies. This very site runs on a clone of it, so the thing announcing the milestone is also the thing being announced, which feels appropriately recursive.

If you run Pi and want an intent store with a wiki, an inbox, and human-gated shaping baked into your sessions:

```
pi install npm:@misabegovic/pi-brain
```

Source is at [github.com/misabegovic/pi-brain](https://github.com/misabegovic/pi-brain). And with the notes from digging through Pi's extension surface still fresh — compaction harvest, context injection, entry renderers — there's a decent roadmap for what those 257 people get next.
